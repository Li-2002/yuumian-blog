如果你接触过<span style="color: rgba(66, 133, 244, 1)">摄影测量、遥感、GIS、测绘</span>这些，那这四个缩写你一定见过：<code>DEM</code>、<code>DTM</code>、<code>DSM</code>、<code>DOM</code>。

它们有个共同点——都是<span style="color: rgba(66, 133, 244, 1)">对地表及其附着物的数字化表达</span>，说白了就是"用一堆数字或者像素，把地球表面这块地方描述出来"。但问题来了，它们描述的东西、拿数据的方式、以及用在哪里，完全不一样，所以新手（包括我，所以才有这一篇文章哈哈哈哈哈）第一次看到这四个词的时候基本都是一个状态：<span style="color: rgba(247, 79, 79, 1)">长得好像，好像都是tif，又好像不是一样……</span>

这篇文章就按我的理解把它们捋一遍，从定义、原理、获取方式、区别联系到典型应用，最后再补几个同样经常出现的"亲戚名词"。

打个比方方便理解：想象你站在太空，伸手去<span style="color: rgba(240, 110, 35, 1)">摸</span>地球表面——

- 你摸到的是屋顶、树冠、桥面 → 这就是 <code>DSM</code>
- 你把房子、树全部"剥掉"，摸到的是<span style="color: rgba(52, 168, 83, 1)">裸地</span> → 这就是 <code>DEM</code>
- 在裸地上再画满山脊线、山谷线、坡度坡向这些"地形特征" → 这就是 <code>DTM</code>
- 而如果你不是用手摸，是用<span style="color: rgba(66, 133, 244, 1)">相机拍</span>了一张"贴在地面上、每个像素都带真实坐标"的照片 → 这就是 <code>DOM</code>

| 术语 | 全称 | 中文 | 表达内容 | 是否包含地表附着物（建筑、树木等） | 数据来源 |
| --- | --- | --- | --- | --- | --- |
| DEM | Digital Elevation Model | 数字高程模型 | 地面（裸地）的高程 | 不包含 | 地形图矢量化、测量、航空摄影测量 |
| DTM | Digital Terrain Model | 数字地形模型 | 地面 + 地形特征（等高线、坡度、坡向等） | 不包含 | 同 DEM，但附加属性更多 |
| DSM | Digital Surface Model | 数字表面模型 | 地表及其上所有附着物的表面 | 包含（屋顶、树冠、桥梁等） | 摄影测量、LiDAR、SAR、无人机 |
| DOM | Digital Orthophoto Map | 数字正射影像图 | 地表的正射校正影像 | 包含（但它本质是"影像"，不是"高程模型"） | 航片/卫星影像正射纠正 |

一句话记忆：<span style="color: rgba(240, 110, 35, 1)">DEM / DTM 看"地形"（裸地），DSM 看"表面"（地物顶端），DOM 看"样子"（照片）。</span>

先不看概念，直接看剖面，一眼就明白了：

```text
                 屋顶                       树冠
                  __                        /\
                 |  |                      /  \        <- DSM：表面，连屋顶树冠一起"摸"
       __________|  |_____________________/    \_______
      /                                                \
     /                                                  \   <- DEM：裸地，房子和树都被剥掉了
    /                                                    \
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

   DSM - DEM = 地物高度（楼高 / 树高 / 积雪厚度……）

   DOM：不是曲线，而是把一张带坐标的照片"贴"在这片地表上
        —— 每个像元记录的是颜色，不是高程
```

## 1. DEM <span style="color: rgba(66, 133, 244, 1)">数字高程模型</span>


<code>DEM</code>（Digital Elevation Model，数字高程模型），是对地球表面<span style="color: rgba(66, 133, 244, 1)">地形起伏形态</span>的数字化表达，以规则格网（Grid）或者 TIN（不规则三角网）的形式记录地面高程。

注意关键词是<span style="color: rgba(240, 110, 35, 1)">"裸地"</span>——它反映的是把建筑物、植被全部剥掉之后的地形，只表达"纯地形"。


- 数据结构：规则格网（最常用，比如 30m、90m 的 SRTM 数据）、等高线、TIN、等高线 + 高程点
- 分辨率跨度很大，从 90 米（SRTM）一直到亚米级都有
- 格网 DEM 其实就是一个"高程矩阵"，每个格子存一个海拔值，用灰度图渲出来就是黑白起伏那种山体阴影效果

来源：
```
- <code>地形图矢量化</code>：人工数字化等高线和高程点，再内插生成
- <code>传统测量</code>：水准测量、全站仪、GPS RTK
- <code>航空摄影测量</code>：立体像对匹配后，人工编辑去掉地物得到裸地
- <code>InSAR / 卫星雷达测高</code>：比如 SRTM、TanDEM-X
- <code>激光雷达（LiDAR）</code>：滤波算法把点云分成地面点和非地面点，取地面点生成 DEM——目前最精确的方式
```
这里有个业界公开的小"瑕疵"：<span style="color: rgba(247, 79, 79, 1)">SRTM 的 C 波段雷达信号穿不透茂密树冠</span>，所以它在植被覆盖区实际上含有树冠高度，严格来说属于 DSM 性质，但大家平时都当 DEM 用。TanDEM-X 也类似。做坡面水文分析之前，最好先确认一下数据有没有"树冠偏移"。



常见的有SRTM（90m / 30m）、ASTER GDEM（30m）、AW3D（30m / 5m）、ALOS World 3D、Copernicus DEM（30m）。



大部分都是用在等高线生成、坡度坡向分析、流域划分、洪水淹没模拟、土方量计算、地质构造分析。

## 2. DTM <span style="color: rgba(66, 133, 244, 1)">数字地形模型</span>


<code>DTM</code>（Digital Terrain Model，数字地形模型）可以理解成 DEM 的<span style="color: rgba(66, 133, 244, 1)">加强版 / 超集</span>。除了高程信息，它还包含地形特征要素：等高线、山脊线、山谷线、坡度、坡向、曲率、地形特征点（峰、洼、鞍部）等等。

所以关系上是：<span style="color: rgba(240, 110, 35, 1)">DTM ⊃ DEM</span>，DEM 只是 DTM 的一部分。

相比于DEM，<code>地形特征线（breakline）</code>——比如山脊线、山谷线、断裂线，这是 DTM 相对 DEM 最典型的"增量"。在摄影测量里，测图员会在立体像对上人工采集这些特征线加入模型，让地形的"骨架"更准确；DEM 只负责"肉"。

来源：
```
- 在 DEM 基础上派生：坡度 / 坡向 / 曲率分析、等高线提取
- 叠加地形特征线（山脊线、山谷线、断裂线）
- 摄影测量 + 人工采集特征线
```


一般用在公路 / 铁路选线（需要坡度、垭口信息）、水土流失分析（坡长坡度因子）、军事地形分析、通视分析（某个点能不能看到另一个点）、风电场选址比较多。

> <span style="color: rgba(240, 110, 35, 1)">行业现状提醒</span>：在实际生产里，尤其是国内测绘系统，DEM 和 DTM 经常不做严格区分，很多文献直接互换着用。所以看到别人混用别急着纠正，先看上下文——但你自己写东西的时候区分清楚，会显得专业不少。

## 3. DSM <span style="color: rgba(66, 133, 244, 1)">数字表面模型</span>


<code>DSM</code>（Digital Surface Model，数字表面模型），是对地球表面<span style="color: rgba(66, 133, 244, 1)">及其上所有自然/人工附着物顶部</span>的数字化表达。

屋顶、树冠、桥梁、电线杆、高架道路——凡是你站在太空"摸到"的<span style="color: rgba(240, 110, 35, 1)">最外层表面</span>，都反映在 DSM 里。它的高程值 = 地面高程 + 地物高度。


<code>DSM − DEM = 地物高度</code>。这个减法撑起了很多场景：建筑高度、树高（冠层高度）、积雪厚度……都靠它算。


来源:
```
- <code>摄影测量 / 无人机航测</code>：多视影像密集匹配（MVS），生成点云后内插成 DSM，这是无人机测绘的主流流程
- <code>机载 LiDAR</code>：直接获取所有回波点（首回波就是表面），滤波前的点云就是 DSM
- <code>卫星立体像对</code>：WorldView、Pleiades、高分七号等
- <code>SAR 干涉测量（InSAR）</code>：全天候，但噪声较多
- <code>SAR 层析（TomoSAR）</code>：可以分离多层散射体，比较前沿
```

一般用在：
- 建筑高度提取 / 城市三维建模：DSM 减去 DEM，得到每栋楼的高度
- 植被冠层高度（<code>CHM</code>）：DSM（树冠顶）− DEM（地面）= 树高，林业碳汇估算的核心数据
- 太阳能屋顶潜力评估（屋顶坡向 + 遮挡分析）
- 电线 / 通信塔高度测量与净空分析
- 导航中的"地表遮挡"分析（高楼区的 GPS 遮挡）
- 洪水模拟里判断哪些屋顶会被淹没
等等

## 4. DOM <span style="color: rgba(66, 133, 244, 1)">数字正射影像图</span>


<code>DOM</code>（Digital Orthophoto Map，数字正射影像图），是利用数字高程模型（DEM）对数字航空影像 / 卫星影像进行<span style="color: rgba(66, 133, 244, 1)">正射纠正（Orthorectification）</span>，消除地形起伏和传感器倾斜造成的几何畸变，再经镶嵌、匀色、裁切，最后带上公里格网、坐标注记等图廓要素的数字化影像产品。

<span style="color: rgba(247, 79, 79, 1)">关键：DOM 不是高程模型，它是影像！</span>每个像元记录的是光谱 / 颜色信息（RGB 或多光谱），而不是高程值。所以把它和 DEM / DSM / DTM 并列其实有点"跨维度"——一个是照片，三个是高度。


他有着：
- <code>几何精度高</code>：每个像元都有准确的地理坐标，可以直接量测距离、面积
- <code>信息量丰富</code>：直观反映地物真实颜色和纹理，"所拍即所得"
- <code>不具备高程信息</code>：单张 DOM 无法直接测高
- 可以叠加等高线、DEM 晕渲等做成复合产品
的特点

来源:
```
1. 航空摄影获取航片（带 POS 数据更好）
2. 空三加密（光束法区域网平差）
3. 利用 DEM 对影像<span style="color: rgba(240, 110, 35, 1)">逐像元</span>做正射纠正
4. 影像镶嵌、匀光匀色、接边处理
5. 按标准分幅裁切、添加图廓整饰 → 得到 DOM
```


地面分辨率（<code>GSD</code>，比如 0.5m、2m）、平面位置中误差（一般要求平地/丘陵 ≤ 图上 0.5mm 这种量级）。



用在国土调查和土地利用现状图底图、城市规划"现状一张图"、灾害评估（震后、洪后对比）、变化检测（两期 DOM 对比发现违建 / 耕地变化）、GIS 底图，我们也用他来做地图。

## 四个的 <span style="color: rgba(66, 133, 244, 1)">关系</span>

```text
┌──────────────────────────────────────────────────┐
│  DSM 数字表面模型                                 │
│  ┌────────────────────────────────────────────┐  │
│  │  建筑顶部、树冠、桥梁等"附着物"             │  │  <- DSM 独有部分
│  ├────────────────────────────────────────────┤  │
│  │                                            │  │
│  │      DTM / DEM 数字高程（地形）模型          │  │
│  │      （裸地表面 + 地形特征）                 │  │
│  │                                            │  │
│  └────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘

DOM：与上面三者不是同一个维度的产品 —— 它是"带坐标的正射照片"
     而生产 DOM，恰恰需要用 DEM 来做正射纠正！
```


- <span style="color: rgba(240, 110, 35, 1)">地物高度 = DSM − DEM</span>（建筑高度、树高 CHM = DSM − DEM、雪深……）
- <span style="color: rgba(240, 110, 35, 1)">DOM = 原始影像 + DEM + 传感器参数 → 正射纠正</span>

## 最容易搞混的 <span style="color: rgba(66, 133, 244, 1)">几个点</span>

### DEM vs DTM

- <span style="color: rgba(66, 133, 244, 1)">严格区分</span>：DEM 只是高程数据；DTM 是高程 + 地形特征要素（等高线、山脊线、坡度等属性）
- <span style="color: rgba(240, 110, 35, 1)">实际使用</span>：多数软件（比如 ArcGIS）里基本混用，DTM 经常被当成 DEM 的同义词
- 英文文献里，欧洲学者更爱用 DTM，美国学者更爱用 DEM

### DEM vs DSM

用生活的例子最好记：

- <span style="color: rgba(52, 168, 83, 1)">DEM</span> = 你想让水自然流动时，"水会走的地面"（裸地，平滑的）
- <span style="color: rgba(240, 110, 35, 1)">DSM</span> = 你往天上扔一个沙袋，沙袋最后停在哪里的高度（表面，波浪形的）

### SRTM 的陷阱

SRTM 的雷达信号穿不过茂密树冠，所以它在林区的数据实际上是<span style="color: rgba(247, 79, 79, 1)">"树冠顶"</span>，严格来说是 DSM，但常被当 DEM 用。做水文、坡度分析之前，先看一眼数据在植被区是不是有系统性偏高。

### 国内测绘系统里的分类

中国测绘语境里常把"<span style="color: rgba(66, 133, 244, 1)">4D 产品</span>"并列：<code>DLG</code> 数字线划图、<code>DEM</code> 数字高程模型、<code>DOM</code> 数字正射影像图、<code>DRG</code> 数字栅格地图。而 <code>DSM</code> 是近年无人机、激光雷达兴起之后才普及的概念，经常被单独拎出来和 DEM 对比讨论。

### DSM 不一定比 DEM "高级"

DSM 信息量大，但它<span style="color: rgba(247, 79, 79, 1)">不适合做水文分析</span>——水流会被屋顶"挡住"，越算越离谱。

- 做洪水模拟、流域分析 → 必须用 DEM
- 做城市建模、测树高 → 必须用 DSM

所以顺序永远是：<span style="color: rgba(240, 110, 35, 1)">先想清楚业务目标，再选数据</span>，而不是哪个听起来高级用哪个。

## 顺便认识几个 <span style="color: rgba(66, 133, 244, 1)">亲戚名词</span>

既然都把 DEM 家族翻出来了，那就再补几个经常跟它们一起出现的：

| 术语 | 全称 | 中文 | 和上面几个的关系 |
| --- | --- | --- | --- |
| CHM | Canopy Height Model | 冠层高度模型 | DSM − DEM 得到的那层"树"，林业里单独当产品用 |
| nDSM | normalized DSM | 归一化数字表面模型 | 就是 DSM − DEM 的结果，把地面归零后只留地物高度 |
| DBM | Digital Building Model | 数字建筑模型 | 关注建筑物本身（轮廓 + 高度 + 结构），城市三维建模常用 |
| DLG | Digital Line Graphic | 数字线划图 | 4D 产品之一，矢量化的道路、水系、境界等图元 |
| DRG | Digital Raster Graphic | 数字栅格地图 | 4D 产品之一，纸质地形图扫描纠正后的栅格图 |
| TIN | Triangulated Irregular Network | 不规则三角网 | 一种高程数据组织方式，DEM/DSM 都能用它存 |
| DGM / DHM | Digitales Geländemodell / Höhenmodell | （德语区的叫法） | 德语文献里对应 DEM / 高程模型，看德文资料时会遇到 |
| Point Cloud | — | 点云 | LiDAR / 密集匹配的直接产物，DEM、DSM 都是从它内插出来的 |
| LOD | Level of Detail | 细节层次 | 城市三维模型的分级（LOD1 是"方块楼"，LOD2 有屋顶结构），常和 DSM/DBM 一起出现 |

简单串一下逻辑：<span style="color: rgba(66, 133, 244, 1)">点云</span>是最原始的原料，滤波后分别得到 <span style="color: rgba(66, 133, 244, 1)">DEM</span>（地面点）和 <span style="color: rgba(66, 133, 244, 1)">DSM</span>（全部点），两个一减得到 <span style="color: rgba(66, 133, 244, 1)">nDSM / CHM</span>，再往上就是 <span style="color: rgba(66, 133, 244, 1)">DBM</span> 和 <span style="color: rgba(66, 133, 244, 1)">LOD 模型</span>；而 <span style="color: rgba(66, 133, 244, 1)">DOM</span> 是从影像那条线来的，顺手还要借用 DEM。

## 获取方式 <span style="color: rgba(66, 133, 244, 1)">横向对比</span>

| 方式 | 可得产品 | 精度 | 成本 | 特点 |
| --- | --- | --- | --- | --- |
| 无人机航测（摄影测量） | DSM、DOM、DLG | 厘米级 | 低 | 灵活，依赖密集匹配算法 |
| 机载 LiDAR | DSM、DEM、点云 | 厘米级 | 高 | 可穿植被缝隙获取地面点 |
| 卫星立体像对 | DSM、DOM | 亚米 ~ 米级 | 中 | 覆盖大，受云影响 |
| InSAR | DSM（DEM） | 米级 | 中 | 全天候，有噪声 |
| 地面测量 / GPS RTK | DEM | 毫米 ~ 厘米 | 高（人工） | 只适用于小范围 |
| 免费公开数据（SRTM 等） | DEM / DSM | 30 ~ 90m | 免费 | 全球覆盖，时效较旧 |

## 选型 <span style="color: rgba(66, 133, 244, 1)">速查表</span>

用的时候直接抄这张表就行：

| 需求 | 应该用什么 |
| --- | --- |
| 洪水淹没模拟、水系提取 | DEM |
| 土方量计算 | DEM（开挖前后对比） |
| 公路选线、坡度分析 | DTM（DEM + 特征线） |
| 城市三维建模、建筑高度 | DSM（减 DEM） |
| 林业碳汇、树高反演 | DSM − DEM = CHM |
| 国土现状调查、底图 | DOM |
| 变化检测 | 两期 DOM（或 DSM）对比 |
| 太阳能屋顶评估 | DSM + DOM |
