## 部署方案

我用的是 Hexo，所以部署起来极其简单。

### Hexo 方案

在博客根目录执行：

```bash
hexo new page air-conditioner
```

然后会生成 `source/air-conditioner/index.md`，把里面的内容全部替换成下面的：

```markdown
---
title: 雨眠牌空调!
date: 2026-07-14 9:50:17
comments: true
aside: false
top_img: false
---

> 炎热夏天来个小空调吹吹~

<style>
.copyright-box a {
  border-bottom: none !important;
  padding: 0 !important;
}
</style>

<div id="air-conditioner-vue"></div>
<script defer data-pjax src='https://npm.elemecdn.com/anzhiyu-air-conditioner@1.0.1/index.3f125bc6.js'></script>
```

然后访问 `https://你的博客域名/air-conditioner`  就能看到了。

### 其他博客方案

如果你用的不是 Hexo，也没关系，直接用 iframe 嵌入就行：

```html
<iframe height="740" src="https://loquacious-bienenstitch-58539b.netlify.app/"></iframe>
```

丢到你想展示的地方就完事了。

### 自行构建部署

如果你想自己折腾一遍源码：

1. 打开项目地址：{% btn 'https://github.com/anzhiyu-c/air-conditioner-vue', 项目地址, anzhiyufont anzhiyu-icon-circle-arrow-right, larger %}
2. 右上角点个 <span style="color: rgba(66, 133, 244, 1)">Star</span>（白嫖归白嫖，Star 还是要给的）
3. Fork 到自己仓库
4. 接入 Vercel 或 Netlify 部署 vercel部署直接点击New Project 找到对应项目直接一直下一步就好了
5. 完事
